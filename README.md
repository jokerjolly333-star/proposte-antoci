# Antoci, proposte sito

Due versioni della stessa pagina, ognuna autonoma (index.html + cartella img/):

- `versione-a/`: le sei foto in griglia 2x3, ognuna si apre dal basso verso l'alto.
- `versione-b/`: le sei foto a pagina di rivista, grandi e piccole alternate, con nome e descrizione.

Apertura con tre foto in dissolvenza, sezione Studio e Contatti sono uguali nelle due versioni.
